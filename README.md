Run by typing the following command:
python Blackjack.py

To alter the parameters, change the values that are initialized in the QLearningAgent class

To alter the episode count, alter the N_EPISODES constant or the parameters in the different functions. The episode count can be individually modified for the training, testing, and video recording in train_agent, test_agent, and record_agent_video respectively.
